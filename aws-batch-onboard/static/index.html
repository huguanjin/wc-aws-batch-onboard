1. 连接 New API

令牌来自 New API「个人设置 → 系统访问令牌」，用户 ID 必须和该令牌所属账号一致。

2. 渠道模板

会自动拼接当前 Region，例如 AWS-us-east-1。

勾选模型后会自动生成映射，不用先清空再点生成。例如 claude-opus-4-8 → global.anthropic.claude-opus-4-8。

先以禁用写入，测活成功才启用进路由池；失败的不会被调度。

会测完该渠道全部模型。全部失败才删渠道；有成功的只去掉失败模型。
